# Photos

`build/`: photos of building and testing the rigs, for the article and the
build guide. Name them `NNNN-<what>.jpg` with a four-digit number in the
order they were taken (`0001-first-pinion-test.jpg`). Failures welcome.
Resize to about 2000 px on the long side before adding them, so the repo
stays small.

credit.
